# キャンプギア棚 v7

今回は **画像のデザインだけではなく、実際に動作するHTMLサイト** として作成しています。

## 方針

- ユーザー提供画像はそのまま使用しない
- 参考の雰囲気だけをもとに、別の新規画像を生成
- その生成画像をトップページの収納ビューとして利用
- 収納を選ぶと、実写風の道具が布の上に広がる画面へ遷移

## 主な特徴

### 1. 画像ベースのトップページ
`assets/storage_scene.png` に、生成したキャンプギア収納画像を入れています。

その上に以下のホットスポットを配置しています。

- リュック類
- クッカー
- ランタン
- 工具・ロープ
- 衣類
- クーラー
- 収納BOX
- 寝具・テント
- 食器

クリックすると、その収納の道具をキャンバス地の布の上に広げます。選んだ収納へ寄るアニメーションの後、道具が順番に広がります。右側の一覧パネルはありません。

画面幅720px以下では、収納の写真を大きく切り出した2列の写真カードを表示します。写真の下に収納名を添え、カード全体のタップで道具を広げます。写真には軽量化した `assets/storage-cards.jpg` を共通で使い、縦にスクロールして収納を選べます。

### 2. 道具の詳細と荷物の選択
広げた道具の写真・名前や、一覧・今回の荷物・状態確認のカードをクリックすると、道具の詳細画面へ移動します。詳細画面には写真・状態・手入れメモ・保管場所・数量・重量・購入情報をまとめています。

詳細画面や、広げた道具の下のボタンから

- 今回持っていく
- 選択解除
- 手入れする（専用画面へ移動）

ができます。「収納棚に戻す」または Escape キーで棚へ戻れます。「今回の荷物」から選択済みの装備を確認できます。写真を登録した道具には、登録写真を優先して表示します。

詳細から「手入れする」で編集画面へ移動し、記録・キャンセル後は詳細へ戻ります。詳細の戻るボタンで、元の一覧や広げた道具へ戻れます。`#gear/道具ID` から直接詳細を開くこともできます。

スマートフォンでは道具を2列で並べます。アニメーションを減らす端末設定にも対応しています。

使用画像・生成プロンプトは [assets/unpack-assets.md](assets/unpack-assets.md) に記録しています。

### ナビゲーション

画面上部から「収納から選ぶ」「道具一覧」「状態確認」「今回の荷物」に移動できます。右端の「…」に、検索・道具追加・キャンプ名編集・テーマ・JSONの読み書きをまとめています。スマートフォンでは上部ナビを2段で表示します。

提案の比較と採用内容は [output/navigation-design.md](output/navigation-design.md) に記録しています。

### 道具の手入れ

「手入れする」から独立した画面へ移動します。布を敷いた作業台に道具の写真を置き、紙のノートに状態・次にする手入れ・しまう場所を記録できます。メーカー・数量・重量・購入の記録は「道具のこと」を開くと編集できます。

「記録して戻る」「記録せず戻る」で、手入れ画面を開いた詳細や一覧へ戻ります。ブラウザの戻る・進むにも対応し、`#maintenance/道具ID` から直接開けます。写真のサイズ・圧縮形式は画面に表示しません。

### 3. 継続して使える管理機能

道具一覧もトップページと同じ布・木・紙札の雰囲気で表示します。キャンバス地の上に実写風の道具を並べ、紙札に名前・しまう場所・数量・重量を記載し、状態は押印風に表示します。登録写真は紙の写真枠で優先表示し、写真のない道具には収納画面と共通の種類別素材を使います。検索と絞り込みは紙のメモ、道具の追加は紙札のボタンにまとめています。

- 道具一覧
- 写真追加
- 写真の自動縮小・圧縮保存
- 購入サイトURL
- 持っていく道具管理
- ドラッグ＆ドロップ
- JSONバックアップ / 復元

## 保存
- 道具情報: localStorage
- 写真: IndexedDB
