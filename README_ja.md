# キャンプギア棚 v7

木の収納棚から道具を選び、布の上に広げてキャンプの準備をするHTMLサイトです。道具一覧・状態確認・今回の荷物・お手入れの画面も、布・木・紙札・金属の質感で揃えています。

## 収納から道具を選ぶ

トップページの収納を選ぶと、その収納の道具をキャンバス地の布の上に広げます。収納へ寄るアニメーションの後、道具が順番に広がります。

写真・名前や、道具一覧・今回の荷物・状態確認の道具をクリックすると詳細画面へ移動します。詳細には写真・状態・お手入れの進み具合・保管場所・数量・重量・購入情報を表示します。`#gear/道具ID` から直接開けます。

画面幅720px以下のトップページは、収納の写真を大きく切り出した2列の写真カードです。写真の下の収納名とカード全体から収納を選べます。

## 画像の軽量化

表示用の画像をWebPへ変換しました。PC用の棚画像は1586×992の解像度を維持しています。

| 表示用素材 | 元画像 | 表示用WebP |
| --- | ---: | ---: |
| PCの収納棚 | 2,753,446 bytes | 239,560 bytes |
| 布と木の背景 | 3,099,986 bytes | 163,896 bytes |
| 透過の道具素材 | 1,792,285 bytes | 368,732 bytes |
| 写真カード用の収納棚 | 142,916 bytes | 128,012 bytes |

PCの棚画像の容量は約91%削減しています。WebP非対応のブラウザ向けに棚のJPEGも用意しています。布と道具素材の先読みは収納を開く時に行い、一覧・荷物・状態確認の写真は、その画面を開いてから読み込みます。初期表示時に隠れた画面の道具一覧を作成しません。

生成時の元PNGは保存し、画面では軽量なWebPを使用します。使用素材・生成プロンプトは [assets/unpack-assets.md](assets/unpack-assets.md) に記録しています。

## 道具一覧と今回の荷物

道具一覧は、布の上に写真や種類別の道具素材を並べ、紙札に名前・保管場所・数量・重量を表示します。状態は押印風に表示します。写真のない道具は収納画面と共通の素材を使用します。

「今回持っていく」も同じ布の上に「棚で待つ道具」と「今回の荷物」を並べます。道具ごとのボタンかドラッグ＆ドロップで移動し、「いつもの装備を入れる」で定番の道具をまとめて選べます。

## 状態確認とお手入れ

状態確認には、点検・修理待ちの道具を写真と紙札で並べます。「作業台で手入れする」から、その道具のお手入れ画面へ移動します。

詳細画面には清掃・乾燥・点検・収納の作業ボタンを置き、作業台への入口にしています。お手入れ画面では、実物の道具で済んだ工程を選んで完了を記録します。途中までの工程も保存できます。4工程を完了して保存すると、前回のお手入れ完了日を記録します。完了した道具で次のお手入れを始める時は、工程を新しく始めます。

作業後の状態と保管場所を選んで戻れます。工程をすべて完了しても、状態が自動的に「使用OK」へ変わることはありません。気づいたことのメモは折りたたみ、メーカー・数量・重量・購入情報も「道具のこと」から編集できます。

保存・取りやめ後は元の詳細や一覧に戻ります。ブラウザの戻る・進むにも対応し、`#maintenance/道具ID` から直接開けます。

## 写真

登録写真を優先して表示します。透過PNG・WebPをアップロードすると、透明部分を保ったまま縮小・圧縮して保存し、布の上に切り抜きとして表示します。背景付きの写真は写真枠で表示します。JPEG自体には透過がなく、任意のJPEGの背景を自動除去する機能はありません。

所持ペグの添付写真は、画像生成ツールで白背景を除去した `assets/owned-gear/titanmania-v-pegs-cutout.webp` を同梱しています。元JPEGも資料として残しています。既存データが同梱の旧JPEGを参照している場合だけ、新しい透過素材へ置き換えます。ユーザーがアップロードした写真や削除済みの写真はそのままです。

## ナビゲーションと保存

上部から収納・道具一覧・状態確認・今回の荷物へ移動できます。「…」には検索・道具追加・キャンプ名編集・テーマ切り替えをまとめています。JSONの読み込み・書き出しと、サンプルに戻す操作は削除しました。

- 道具情報・お手入れの工程・今回の荷物：このブラウザのlocalStorage
- アップロードした写真：このブラウザのIndexedDB
- 同梱の写真・背景：リポジトリ内の `assets/`

道具のデータは端末・ブラウザごとに保存され、GitHubへは送信しません。

## 立体表示を追加する場合

現在は写真・透過素材による2D表示です。上下左右に回して裏側まで見るには、道具ごとの3Dモデルが必要です。WebではGLB/glTFを使い、[model-viewerのカメラ操作](https://modelviewer.dev/examples/stagingandcameras/)などで回転・ズームを追加できます。

3Dモデルを用意する方法は、メーカーの3Dデータを利用する、寸法・形状をもとにモデリングする、実物を全方向から重なりのある写真で撮影して復元する、のいずれかです。[Appleの写真撮影ガイド](https://developer.apple.com/documentation/realitykit/capturing-photographs-for-realitykit-object-capture)も複数方向からの撮影を説明しています。写真1枚から見えない面の実際の形状は確定できません。重いモデルは表示を開いた時に読み込む構成にできます。
